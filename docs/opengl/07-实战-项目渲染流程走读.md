## 7.1 渲染相关文件总览

```
my_demo/
├── main.cpp                 ← 设置 OpenGL 版本 + 创建窗口
├── MainWindow.cpp           ← 游戏循环 (每 16ms 的入口)
├── RenderWidget.cpp         ← 渲染核心 (initializeGL / paintGL / cleanupGL)
├── Engine.h                 ← ECS 引擎 (管理 World + 组件注册)
│
├── Components/
│   ├── TransformComponent.h  ← Model 矩阵 (position/rotation/scale)
│   ├── MeshComponent.h       ← VAO/VBO/EBO 句柄
│   ├── MaterialComponent.h   ← ambient/diffuse/specular/shininess
│   └── CameraComponent.h     ← 摄像机数据
│
├── System/
│   ├── Shader.h              ← 着色器编译/链接/Uniform 设置
│   ├── MeshFactory.h         ← 创建立方体 VAO
│   └── EditorCamera.h        ← 编辑器摄像机 (WASD 移动)
│
└── Shaders/
    ├── default.vert          ← 顶点着色器 (MVP 变换)
    ├── default.frag          ← 片段着色器 (Blinn-Phong 光照)
    ├── line.vert / line.frag ← Gizmo 辅助线着色器
```

## 7.3 第二步：OpenGL 初始化 (RenderWidget::initializeGL)

```cpp
void RenderWidget::initializeGL() {
    // ① 获取 OpenGL 函数指针 (Qt 封装的)
    initializeOpenGLFunctions();
    
    // ② 开启深度测试 (被遮挡的像素不画)
    glEnable(GL_DEPTH_TEST);
    
    // ③ 加载着色器
    m_shader.load("default.vert", "default.frag");
    //   内部: 读文件 → 编译顶点着色器 → 编译片段着色器
    //        → 链接为着色器程序 → glUseProgram 可用
    
    m_lineShader.load("line.vert", "line.frag");
    
    // ④ 初始化 Gizmo
    initGizmo();
    //   创建 VAO + VBO → 画 6 条线 (XYZ 正负半轴)
}
```

## 7.4 第三步：游戏循环 (每 16ms)

```cpp
// MainWindow 构造函数中设置:
connect(m_timer, &QTimer::timeout, [this]() {
    float dt = m_elapsed.restart() / 1000.f;  // 帧间隔
    
    if (m_isPlaying) {
        // Play 模式: 注入输入给脚本
        scriptSetInput(in.keyDown, in.mouseDX, in.mouseDY);
        m_engine->runFrame(dt);   // ← 执行所有 System
    } else {
        // Edit 模式: 更新编辑器摄像机
        m_editorCam.update(dt, float(width()) / max(height(), 1));
        m_engine->runFrame(dt);   // ← 同样执行 System
    }
    
    in.endFrame();          // 清除输入增量
    m_renderWidget->update(); // ← 触发 paintGL
});
```

## 7.5 第四步：ECS System 执行 (Engine::runFrame)

```cpp
void Engine::runFrame(float dt) {
    for (auto *s : m_systems)
        s->update(m_world, dt);
    //    ↑
    //  依次执行: RotationSystem → ScriptSystem
}

// RotationSystem: 修改 rotation.y += speedY * dt
// ScriptSystem:  调用 Lua 的 update(dt)，脚本可修改 Transform
```

## 7.6 第五步：渲染 (RenderWidget::paintGL)

### 完整代码走读

```cpp
void RenderWidget::paintGL() {
    // ===== ① 清屏 =====
    glClearColor(0.15f, 0.15f, 0.2f, 1.0f);  // 深蓝灰背景
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
    //       清除颜色缓冲         +   清除深度缓冲

    if (!m_world || !m_shader.isValid()) return;

    // ===== ② 确定摄像机 =====
    glm::mat4 view, proj;
    glm::vec3 cameraPos;
    
    if (m_editorCam) {
        // 编辑模式 → 用编辑器摄像机
        view = m_editorCam->viewMatrix;
        proj = m_editorCam->projMatrix;
        cameraPos = m_editorCam->position;
    } else {
        // Play 模式 → 找场景中 active=true 的 CameraComponent
        m_world->each([&](flecs::entity, const CameraComponent &cam) {
            if (cam.active) {
                view = cam.viewMatrix;
                cameraPos = cam.position;
            }
        });
    }

    // ===== ③ 画 Gizmo =====
    drawGizmo(view, proj);
    //   用 lineShader 画 6 条线:
    //     正半轴: 红色 → gluLookAt 方向
    //     负半轴: 暗红色

    // ===== ④ 设置主着色器 + 全局 Uniform =====
    m_shader.use();
    m_shader.setMat4("uView", view);
    m_shader.setMat4("uProjection", proj);
    m_shader.setVec3("uCameraPos", cameraPos);
    
    // 方向光 (模拟太阳光，从上往下照)
    m_shader.setVec3("uLight.direction", -0.3f, -0.7f, -0.5f);
    m_shader.setVec3("uLight.ambient",   0.2f, 0.2f, 0.2f);
    m_shader.setVec3("uLight.diffuse",   0.8f, 0.8f, 0.8f);
    m_shader.setVec3("uLight.specular",  1.0f, 1.0f, 1.0f);

    // ===== ⑤ 遍历实体，逐个绘制 =====
    m_world->each([this](flecs::entity e, TransformComponent &tf,
                         const MeshComponent &ms) {
        if (!ms.isValid()) return;  // 跳过没 VAO 的

        // ⑤-a: 设 Model 矩阵 (每个实体不同)
        m_shader.setMat4("uModel", tf.getModelMatrix());
        m_shader.setMat3("uNormalMatrix", tf.getNormalMatrix());

        // ⑤-b: 设材质 (可选组件，用 C API 查询)
        const auto *mat = static_cast<const MaterialComponent*>(
            ecs_get_id(m_world->c_ptr(), e.raw_id(),
                       m_world->component<MaterialComponent>().raw_id()));
        if (mat) {
            m_shader.setVec3("uMaterial.ambient",   mat->ambient);
            m_shader.setVec3("uMaterial.diffuse",   mat->diffuse);
            m_shader.setVec3("uMaterial.specular",  mat->specular);
            m_shader.setFloat("uMaterial.shininess", mat->shininess);
        } else {
            // 默认灰色材质
            m_shader.setVec3("uMaterial.ambient",   0.2f, 0.2f, 0.2f);
            m_shader.setVec3("uMaterial.diffuse",   0.7f, 0.7f, 0.7f);
            m_shader.setVec3("uMaterial.specular",  1.0f, 1.0f, 1.0f);
            m_shader.setFloat("uMaterial.shininess", 32.0f);
        }

        // ⑤-c: 绘制
        glBindVertexArray(ms.vao);
        if (ms.hasIndices)
            glDrawElements(ms.primitiveType, ms.indexCount,
                          GL_UNSIGNED_INT, nullptr);
        else
            glDrawArrays(ms.primitiveType, 0, ms.vertexCount);
        glBindVertexArray(0);
    });
}
```

## 7.7 第六步：GPU 执行着色器

```
glDrawElements 触发后，GPU 自动:

  for each 顶点 (i = 0; i < 36; i++):
    ┌─────────────────────────────────────────────────┐
    │ 顶点着色器 (default.vert) 执行 1 次:              │
    │   输入:  aPos = VBO[ebo[i]] 的位置               │
    │          aNormal = VBO[ebo[i]] 的法线             │
    │                                                  │
    │   worldPos = uModel * vec4(aPos, 1.0)            │
    │   vFragPos = worldPos.xyz     → 输出给片段着色器   │
    │   vNormal  = normalize(uNormalMatrix * aNormal)   │
    │   gl_Position = uProj * uView * worldPos         │
    └─────────────────────────────────────────────────┘

  for each 像素 (光栅化产生的每个片段):
    ┌─────────────────────────────────────────────────┐
    │ 片段着色器 (default.frag) 执行 1 次:              │
    │   输入:  vFragPos (插值后的世界位置)              │
    │          vNormal  (插值后的法线)                  │
    │                                                  │
    │   ambient  = uLight.ambient * uMaterial.ambient  │
    │   diffuse  = uLight.diffuse * max(N·L,0) * mat   │
    │   specular = uLight.specular * (N·H)^shininess   │
    │                                                  │
    │   fragColor = vec4(ambient+diffuse+specular, 1)  │
    └─────────────────────────────────────────────────┘

  深度测试: 这个像素被遮挡了吗? → 通过就写入帧缓冲
  → 最终显示在屏幕上
```

## 7.8 清理 (cleanupGL)

```cpp
void RenderWidget::cleanupGL() {
    makeCurrent();  // 激活 GL 上下文
    
    // ① 清理所有实体上的 GPU 资源
    m_world->each([this](flecs::entity, MeshComponent &ms) {
        if (ms.vao) m_factory.destroyMesh(ms);
        //   glDeleteVertexArrays + glDeleteBuffers
    });
    
    // ② 清理 Gizmo
    glDeleteVertexArrays(1, &m_gizmoVao);
    glDeleteBuffers(1, &m_gizmoVbo);
    
    // ③ 清理着色器程序
    m_shader.clear();      // glDeleteProgram
    m_lineShader.clear();
    
    doneCurrent();
}
```

## 7.9 完整数据流图

```
游戏循环 (每 16ms)
│
├── System::update (修改 Transform)
│     RotationSystem → tf.rotation.y += speedY * dt
│     ScriptSystem   → Lua: self:set_position(x, y, z)
│
├── renderWidget->update() → 触发 paintGL()
│     │
│     ├── ① glClear (清屏)
│     │
│     ├── ② 取摄像机矩阵 (EditorCamera / CameraComponent)
│     │       view = lookAt(...)
│     │       proj = perspective(45°, aspect, 0.1, 100)
│     │
│     ├── ③ 画 Gizmo (line shader)
│     │
│     ├── ④ 设全局 Uniform (view, proj, cameraPos, light)
│     │
│     └── ⑤ 遍历实体:
│           for each (Transform + Mesh) entity:
│             ├── setMat4("uModel", tf.getModelMatrix())
│             ├── setMat3("uNormalMatrix", tf.getNormalMatrix())
│             ├── 读 MaterialComponent (可选)
│             ├── glBindVertexArray(mesh.vao)
│             └── glDrawElements(GL_TRIANGLES, 36, ...)
│                   │
│                   └── GPU 执行 default.vert + default.frag
│
└── → 像素写入帧缓冲 → 屏幕显示
```

## 7.10 总结

```
本项目的渲染体系:

  组件 (数据)          System (逻辑)         渲染 (显示)
  ─────────           ────────────          ────────
  TransformComponent                     → Model 矩阵
  MeshComponent                           → VAO 绑定 + glDraw
  MaterialComponent                       → Uniform 材质参数
  CameraComponent                         → View/Proj 矩阵
  RotateBehavior       RotationSystem      → 改 Transform
  ScriptComponent      ScriptSystem        → Lua 改 Transform

  EditorCamera         直接读取 Input      → View/Proj 矩阵

所有数据 ∃ ECS World 中，每帧:
  System 改数据 → paintGL 读数据 → 渲染
```
