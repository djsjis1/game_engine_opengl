# 01 · OpenGL 渲染管线概述

> 理解"从数据到像素"的完整流程，是学习 OpenGL 的第一步。

---

## 1.1 渲染管线是什么？

### 通俗类比

```
OpenGL 渲染管线 ≈ 工厂流水线

  CPU 端                           GPU 端
  ──────                          ──────
  你提供:                         自动处理:
  ┌─────────┐                    ┌──────────────┐
  │ 顶点数据  │ ──传入──→        │ 顶点着色器    │ ← 你写的 GLSL
  │ (xyz坐标) │                  ├──────────────┤
  └─────────┘                    │ 图元装配      │ ← GPU 自动
                                 ├──────────────┤
                                 │ 光栅化        │ ← GPU 自动
                                 ├──────────────┤
                                 │ 片段着色器    │ ← 你写的 GLSL
                                 ├──────────────┤
                                 │ 测试与混合    │ ← GPU 自动
                                 └──────┬───────┘
                                        ↓
                                   屏幕上的像素
```

**关键认知**：你只控制两个环节（顶点着色器、片段着色器），其余是 GPU 硬件自动完成的。

## 1.2 各阶段职责

```
阶段 1: 顶点着色器 (Vertex Shader) — 处理每个顶点
┌──────────────────────────────────────────────┐
│ 输入: 顶点的 3D 坐标 (x, y, z)                │
│ 任务: 把 3D 坐标变换为屏幕坐标                 │
│ 输出: gl_Position (裁剪空间坐标)               │
│                                              │
│ 示例:                                        │
│   世界坐标 (0, 0, 2)                          │
│     → Model矩阵 → World坐标                    │
│     → View矩阵  → 摄像机相对坐标                │
│     → Proj矩阵  → 裁剪空间坐标 (-1 到 1)       │
│     → gl_Position                             │
└──────────────────────────────────────────────┘
                    ↓
阶段 2: 图元装配 (Primitive Assembly) — GPU 自动
┌──────────────────────────────────────────────┐
│ 把 3 个顶点组装成一个三角形                    │
│ 把 2 个顶点组装成一条线段                      │
│ 裁掉视野外的部分                               │
└──────────────────────────────────────────────┘
                    ↓
阶段 3: 光栅化 (Rasterization) — GPU 自动
┌──────────────────────────────────────────────┐
│ 把三角形"填满"成一个个像素点（片段）            │
│                                              │
│    △ 三角形                                   │
│   ███ 光栅化后 = 很多个像素                    │
│  █████                                        │
│                                              │
│ 为每个像素自动插值顶点数据                      │
│ (颜色、法线、纹理坐标...)                       │
└──────────────────────────────────────────────┘
                    ↓
阶段 4: 片段着色器 (Fragment Shader) — 处理每个像素
┌──────────────────────────────────────────────┐
│ 输入: 插值后的像素数据（法线、颜色...）         │
│ 任务: 计算这个像素最终是什么颜色                │
│ 输出: fragColor (RGBA)                        │
│                                              │
│ 示例:                                        │
│   → 环境光 + 漫反射 + 镜面反射 = 最终颜色       │
│   → fragColor = vec4(result, 1.0)             │
└──────────────────────────────────────────────┘
                    ↓
阶段 5: 测试与混合 — GPU 自动
┌──────────────────────────────────────────────┐
│ 深度测试: 这个像素被遮挡了吗?                  │
│ 模板测试: 是否在遮罩范围内?                    │
│ 混合: 多个透明物体怎么叠加?                    │
│                                              │
│ 通过测试的像素 → 写入帧缓冲 → 屏幕显示          │
└──────────────────────────────────────────────┘
```

## 1.3 第一个三角形怎么来的？

```
从 C++ 代码到屏幕的最简路径:

┌─ C++ 端 ─────────────────────────────────────────────────┐
│                                                           │
│  ① 准备顶点数据                                           │
│     float vertices[] = {                                 │
│         -0.5, -0.5, 0.0,  // 左下角                       │
│          0.5, -0.5, 0.0,  // 右下角                       │
│          0.0,  0.5, 0.0   // 顶部                         │
│     };                                                   │
│                                                           │
│  ② 创建 VAO + VBO                                        │
│     glGenVertexArrays(1, &vao);                          │
│     glGenBuffers(1, &vbo);                               │
│     glBindVertexArray(vao);                              │
│     glBindBuffer(GL_ARRAY_BUFFER, vbo);                  │
│     glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), ...);│
│     glVertexAttribPointer(0, 3, GL_FLOAT, ...);          │
│     glEnableVertexAttribArray(0);                        │
│                                                           │
│  ③ 编译着色器程序                                         │
│     GLuint program = 创建+编译+链接(vertexShader,         │
│                                     fragmentShader);     │
│                                                           │
│  ④ 绘制                                                   │
│     glUseProgram(program);                                │
│     glBindVertexArray(vao);                              │
│     glDrawArrays(GL_TRIANGLES, 0, 3);                    │
│                                                           │
└───────────────────────────────────────────────────────────┘
                         ↓
┌─ GPU 端 (自动) ──────────────────────────────────────────┐
│                                                           │
│  顶点着色器 (每个顶点执行 1 次):                            │
│    #version 330 core                                      │
│    layout(location=0) in vec3 aPos;                       │
│    void main() {                                          │
│        gl_Position = vec4(aPos, 1.0);                     │
│    }                                                      │
│                                                           │
│  片段着色器 (每个像素执行 1 次):                            │
│    #version 330 core                                      │
│    out vec4 fragColor;                                    │
│    void main() {                                          │
│        fragColor = vec4(1.0, 0.5, 0.2, 1.0); // 橙色      │
│    }                                                      │
│                                                           │
└───────────────────────────────────────────────────────────┘
                         ↓
                    屏幕上的橙色三角形
```

## 1.4 核心概念速查表

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **VAO** (顶点数组对象) | 顶点数据的"配置清单" | 一份菜单，告诉 GPU "VBO 在哪、每个顶点怎么读" |
| **VBO** (顶点缓冲对象) | 顶点数据的"仓库" | 一个数组，存着所有顶点的坐标/法线/颜色... |
| **EBO** (索引缓冲对象) | 复用顶点的"索引表" | 矩形 4 个顶点，用 6 个索引画 2 个三角形 |
| **Shader** (着色器) | 跑在 GPU 上的小程序 | 顶点着色器处理顶点，片段着色器处理像素 |
| **Uniform** | 全局参数 | 所有顶点/像素共享的值（如 MVP 矩阵、光源位置） |
| **Attribute** | 每个顶点独有的数据 | 每个顶点的坐标、法线、颜色... |

## 1.5 Qt + OpenGL 的特殊性

本项目使用 Qt 封装 OpenGL，有一些特殊点：

```cpp
// Qt 方式获取 OpenGL 函数：
class RenderWidget : public QOpenGLWidget, protected QOpenGLFunctions_3_3_Core {
    void initializeGL() override {
        initializeOpenGLFunctions();  // ← 必须第一步调用！
        // 之后才能使用 gl* 函数
    }
};

// Qt 管理 OpenGL 上下文：
// makeCurrent()   → 激活这个 widget 的 GL 上下文
// doneCurrent()   → 释放上下文
// paintGL()       → Qt 自动调用的绘制函数
```

## 1.6 总结

```
OpenGL ≠ 一个画图的库

OpenGL = 一个 GPU 编程接口

你写的是:
  ① 顶点数据 (C++ float 数组)
  ② 着色器程序 (GLSL)
  ③ 绘制命令 (glDrawArrays)

GPU 帮你做:
  装配 → 光栅化 → 插值 → 像素计算 → 显示

着色器是你控制 GPU 的唯一入口。
```
