# 01 · Lua 虚拟机与栈

> 这是 Lua 调用 C++ 系列的第一篇。理解栈是理解一切的前提。

---

## 1.1 什么是 Lua 虚拟机（lua_State）？

### 通俗类比

```
Lua 虚拟机 ≈ 一个独立的"宇宙"

这个宇宙里有：
- 全局表 (_G)：宇宙里的所有"公共物品"（print、math.sin、string.sub...）
- 注册表 (registry)：宇宙的"保险柜"（C 端存放数据，Lua 端看不到）
- 栈 (stack)：宇宙的"传送带"（C↔Lua 之间传递数据的通道）
```

### 一个进程可以有多个 VM

```
进程
├── lua_State *L1  ← 全局 VM（每个脚本实体共享）
├── lua_State *L2  ← 如果你愿意，可以再开一个独立 VM
└── ...
```

**本项目做法**：全局只创建一个 `lua_State`，所有脚本实体共用。每个实体用独立 table 做"沙盒"隔离。

### 创建和销毁

```c
// 创建
lua_State *L = luaL_newstate();  // 分配内存，初始化
luaL_openlibs(L);                // 加载标准库（print、math、string...）

// ... 使用 ...

// 销毁
lua_close(L);  // 释放所有资源
```

## 1.2 栈 —— C 和 Lua 之间唯一的通信通道

### 为什么需要栈？

C 和 Lua 是两种完全不同的语言，内部数据表示完全不同：

```
C 的内存布局:              Lua 的内存布局:
┌─────────┐               ┌─────────────────┐
│ struct  │               │  GCObject (可变)  │
│ 固定布局 │               │  带类型标记       │
│ 编译时确定│               │  运行时确定       │
└─────────┘               └─────────────────┘
```

**栈就是翻译层**。所有数据进出 Lua VM，都必须经过栈。

### 栈的直观理解

```
Lua 栈（一个数组，索引从 1 开始）

   栈顶 → ┌──────────┐
          │  "hello" │  ← 索引 -1（从栈顶倒数）
          ├──────────┤
          │    42    │  ← 索引 -2
          ├──────────┤
          │  3.14    │  ← 索引 -3
   栈底 → └──────────┘  ← 索引 1（正数，从栈底数）

   正索引：1, 2, 3, ...（从栈底往上数）
   负索引：-1, -2, -3, ...（从栈顶往下数，Lua 函数常用）
```

### 核心操作

| 操作 | 含义 | C API |
|------|------|-------|
| **压栈 (push)** | 把 C 值放入栈顶 | `lua_pushnumber(L, 3.14)` |
| **出栈 (pop)** | 移除栈顶的 N 个值 | `lua_pop(L, N)` |
| **取值 (get)** | 按索引读值（不移除） | `lua_tonumber(L, 1)` |
| **检查** | 取值 + 类型校验 | `luaL_checknumber(L, 1)` |
| **栈顶位置** | 获取当前栈顶索引 | `lua_gettop(L)` |

### 动手实验

```c
// 初始状态
printf("%d\n", lua_gettop(L));  // → 0（空栈）

// 压入三个值
lua_pushnumber(L, 3.14);       // 栈: [3.14]
lua_pushinteger(L, 42);        // 栈: [3.14, 42]
lua_pushstring(L, "hello");    // 栈: [3.14, 42, "hello"]

printf("%d\n", lua_gettop(L));  // → 3

// 按索引读值
double  d = lua_tonumber(L, 1);    // 3.14（索引 1）
int64_t i = lua_tointeger(L, 2);   // 42
const char *s = lua_tostring(L, 3); // "hello"

// 也可以用负索引
const char *s2 = lua_tostring(L, -1); // "hello"（栈顶）

// 弹出 2 个值
lua_pop(L, 2);                  // 栈: [3.14]
printf("%d\n", lua_gettop(L));  // → 1
```

## 1.3 关键原则

### 原则 1：栈是 C 函数操作 Lua 数据的唯一入口

```c
// ❌ 不能这样直接访问 Lua 变量
// int x = luaget("myVar");  // 不存在这样的 API

// ✅ 必须先压栈
lua_getglobal(L, "myVar");   // 把 _G["myVar"] 的值压到栈顶
int x = lua_tointeger(L, -1); // 从栈顶取
lua_pop(L, 1);                // 清理
```

### 原则 2：C 函数通过返回值告诉 Lua "我返回了几个值"

```c
// 这个 C 函数暴露给 Lua 后用: local x, y = myFunc()
static int myFunc(lua_State *L) {
    lua_pushnumber(L, 10);  // 返回值 1
    lua_pushnumber(L, 20);  // 返回值 2
    return 2;  // ← 告诉 Lua VM: "我返回了 2 个值"
}

// Lua 端:
// local a, b = myFunc()   → a = 10, b = 20
```

### 原则 3：C 函数从栈读取参数，往栈写返回值

```
Lua 调用 C 函数时，栈的初始状态:

  栈顶 → ┌──────────────┐
         │   参数 N      │
         ├──────────────┤
         │   参数 N-1    │
         ├──────────────┤
         │     ...      │
         ├──────────────┤
         │   参数 1      │  ← luaL_checknumber(L, 1)
  栈底 → └──────────────┘

C 函数执行完，栈上的参数被自动移除。
C 函数压入的新值成为返回值传给 Lua 端。
```

## 1.4 常用压栈函数速查

| 函数 | 压入的类型 |
|------|-----------|
| `lua_pushnil(L)` | nil |
| `lua_pushboolean(L, b)` | bool |
| `lua_pushnumber(L, n)` | float64（Lua 只有一种数字） |
| `lua_pushinteger(L, i)` | int64 |
| `lua_pushstring(L, s)` | string（内部复制一份） |
| `lua_pushlstring(L, s, len)` | string（指定长度，可含 \0） |
| `lua_pushcfunction(L, f)` | C 函数指针 |
| `lua_pushlightuserdata(L, p)` | 裸指针（无元表，不管理生命周期） |

---

## 1.5 常用取值函数速查

| 函数 | 返回 |
|------|------|
| `lua_toboolean(L, idx)` | bool |
| `lua_tonumber(L, idx)` | double（失败返回 0） |
| `lua_tointeger(L, idx)` | int64_t |
| `lua_tostring(L, idx)` | const char*（失败返回 NULL） |
| `lua_touserdata(L, idx)` | void* |
| `lua_isfunction(L, idx)` | 是否为函数 |
| `lua_isnil(L, idx)` | 是否为 nil |
| `lua_type(L, idx)` | 类型枚举值 |

### 有校验的版本（推荐）

```c
// luaL_check* 系列：类型不对时抛 Lua 错误（不会返回）
float x = (float)luaL_checknumber(L, 1);  // 参数 1 必须是数字
const char *s = luaL_checkstring(L, 2);   // 参数 2 必须是字符串
luaL_checktype(L, 3, LUA_TFUNCTION);      // 参数 3 必须是函数
```

## 1.6 总结

```
           ┌──────────────────────────────────┐
           │           lua_State               │
           │                                  │
  C 代码 ──│── push ──→ [栈] ── pop ──→ Lua  │
  C 代码 ←── tonumber/ ─ [栈] ←── push ── Lua │
           │   tostring                       │
           └──────────────────────────────────┘

核心要点:
  1. 栈是 C↔Lua 的唯一通信通道
  2. C 函数参数从栈底开始 (索引 1)，返回值压入栈顶
  3. return N 告诉 Lua "我返回了 N 个值"
  4. 负索引从栈顶倒数 (-1 = 栈顶)
```
