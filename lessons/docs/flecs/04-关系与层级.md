# 04 · 关系与层级

> Relationship 概念、ChildOf 父子层级、树遍历、场景图构建。

---

## 4.1 什么是关系（Relationship）

关系是 Flecs 的核心特性：**实体与实体之间的连接**。

```cpp
// 语法：entity.add<Relation>(target)
// 含义："entity 对 target 有 Relation 关系"

struct Likes { };
struct Eats { };

flecs::entity alice = ecs.entity("Alice");
flecs::entity bob = ecs.entity("Bob");
flecs::entity apple = ecs.entity("Apple");

alice.add<Likes>(bob);      // Alice likes Bob
alice.add<Eats>(apple);     // Alice eats Apple
```

关系在内部存储为**配对（Pair）**：`(Relation, Target)`。

---

## 4.2 查询关系

```cpp
// 查询所有 "Likes" 关系
ecs.each<Likes>([](flecs::entity e, Likes) {
    // e 是 source（Alice）
    // 需要获取 target（Bob）：
    flecs::entity target = e.target<Likes>();
});

// 查询特定配对：谁 likes Bob？
ecs.query_builder()
    .with<Likes>(bob)   // 指定 target = Bob
    .each([](flecs::entity e) {
        // e = Alice（likes Bob 的人）
    });
```

---

## 4.3 ChildOf：父子层级

`ChildOf` 是 Flecs 内置关系，用于构建**树形层级**（场景图）：

```cpp
flecs::entity root = ecs.entity("Scene");
flecs::entity car = ecs.entity("Car");
flecs::entity wheel = ecs.entity("Wheel");

// 建立层级：Car 是 Scene 的子，Wheel 是 Car 的子
car.child_of(root);
wheel.child_of(car);
```

等价写法：

```cpp
car.add<flecs::ChildOf>(root);
```

---

## 4.4 层级查询

```cpp
// 获取父实体
flecs::entity parent = wheel.parent();  // → Car

// 遍历所有子实体
car.children([](flecs::entity child) {
    // child = Wheel（以及 Car 的其他子实体）
});

// 检查是否有父
bool hasParent = wheel.parent().is_alive();

// 获取层级深度
int depth = 0;
for (flecs::entity p = wheel.parent(); p.is_alive(); p = p.parent())
    depth++;  // wheel: depth=2 (Wheel→Car→Scene)
```

---

## 4.5 递归遍历整棵树

```cpp
void traverse(flecs::entity e, int indent = 0) {
    // 打印当前节点
    std::cout << std::string(indent * 2, ' ') << e.name() << "\n";
    // 递归子节点
    e.children([&](flecs::entity child) {
        traverse(child, indent + 1);
    });
}

traverse(root);
// 输出:
// Scene
//   Car
//     Wheel
```

---

## 4.6 级联删除

**销毁父实体时，所有子实体自动被销毁**：

```cpp
root.destruct();  // Scene 被删 → Car 被删 → Wheel 被删
```

这是 ChildOf 的内置行为，无需手动管理。

## 4.7 场景图典型结构

```
Scene (root)
├── Camera
├── DirectionalLight
├── Player
│   ├── Body (Mesh)
│   ├── Weapon (Mesh)
│   └── Hitbox (Collider)
├── Enemy_01
│   ├── Body (Mesh)
│   └── HealthBar (UI)
└── Environment
    ├── Floor
    ├── Wall_North
    └── Wall_South
```

```cpp
// 构建
auto scene = ecs.entity("Scene");
auto player = ecs.entity("Player").child_of(scene);
auto weapon = ecs.entity("Weapon").child_of(player);

// 移动 Player → Weapon 跟着动（在变换传播系统中实现）
```

## 4.8 解除父子关系

```cpp
// 方式 1：移到另一个父下
wheel.child_of(newParent);

// 方式 2：变为根节点（无父）
wheel.remove<flecs::ChildOf>();
// 或
wheel.remove<flecs::ChildOf>(car);  // 指定解除与 car 的关系
```

---

## 4.9 自定义关系（超越 ChildOf）

```cpp
struct Follows { };    // A 跟随 B
struct OwnedBy { };   // A 属于 B
struct Targeting { }; // A 瞄准 B

enemy.add<Follows>(player);     // 敌人跟随玩家
bullet.add<OwnedBy>(player);    // 子弹属于玩家
turret.add<Targeting>(enemy);   // 炮塔瞄准敌人

// 查询：谁在跟随 player？
ecs.query_builder()
    .with<Follows>(player)
    .each([](flecs::entity e) {
        // e = 所有跟随 player 的实体
    });
```

---

## 4.10 关系 + 组件数据

关系本身可以携带数据（关系组件）：

```cpp
struct Distance { float value = 0; };

// Alice 与 Bob 之间的距离 = 5.0
alice.set<Distance>(bob, {5.0f});  // 配对组件

// 读取
const Distance *d = alice.get<Distance>(bob);
```
