# 02 · 组件与实体操作

> 组件的完整生命周期、实体增删改查、Tag 组件、单例组件。

---

## 2.1 定义组件

任何 struct 都可以当组件，无需继承基类：

```cpp
struct Position { float x = 0, y = 0; };
struct Health { int hp = 100; int maxHp = 100; };
struct Sprite { int textureId = 0; int frame = 0; };
```

**建议**：组件保持纯数据（POD-like），不放逻辑方法。逻辑放 System 里。

---

## 2.2 组件操作

```cpp
flecs::entity e = ecs.entity("Player");

// 添加 + 赋值（set = 有则覆盖，无则添加）
e.set<Position>({10, 20});
e.set<Health>({100, 100});

// 只添加不赋值（用默认构造）
e.add<Sprite>();

// 读取（const，不存在返回 nullptr）
const Position *p = e.get<Position>();
if (p) { /* 有 Position */ }

// 可写（修改后需通知）
Position *pw = e.get_mut<Position>();
pw->x += 5;
e.modified<Position>();  // 触发 OnSet 钩子

// 检查
bool has = e.has<Health>();  // true

// 移除
e.remove<Sprite>();

// 确保有（无则添加默认值，有则不动）
e.ensure<Health>();
```

## 2.3 实体生命周期

```cpp
// 创建
flecs::entity e = ecs.entity();           // 匿名
flecs::entity e2 = ecs.entity("Boss");    // 带名字（调试/查找用）

// 按名字查找
flecs::entity found = ecs.entity("Boss");  // 找到同一个实体

// 是否存活
bool alive = e.is_alive();

// 销毁（连带所有组件 + 子实体）
e.destruct();

// 克隆（复制所有组件到新实体）
flecs::entity clone = e.clone();
```

## 2.4 Tag 组件（无数据标记）

Tag 是空 struct，只表示"有这个标记"，不携带数据：

```cpp
struct Enemy { };      // 空 struct = Tag
struct Boss { };
struct Invisible { };

e.add<Enemy>();        // 标记为敌人
e.add<Boss>();         // 标记为 Boss

// 查询所有 Boss 敌人
ecs.each<Enemy, Boss>([](flecs::entity e, Enemy, Boss) {
    // 只处理同时是 Enemy + Boss 的实体
});

// 移除标记
e.remove<Boss>();
```

**用途**：状态标记（IsDead、IsFrozen）、分类（NPC、Item）、能力标记（CanFly）。

## 2.5 单例组件（Singleton）

全局只有一份的组件（如游戏配置、全局时间）：

```cpp
struct GameConfig {
    float gravity = -9.8f;
    int maxPlayers = 4;
};

// 设置单例（挂在 world 自身）
ecs.set<GameConfig>({-9.8f, 4});

// 读取单例
const GameConfig *cfg = ecs.get<GameConfig>();

// 在系统中使用
ecs.system<Position>()
    .each([&](Position &p) {
        const GameConfig *cfg = ecs.get<GameConfig>();
        // 用 cfg->gravity ...
    });
```

## 2.6 多组件一次性操作

```cpp
// 链式设置多个组件
ecs.entity("Player")
    .set<Position>({0, 0})
    .set<Velocity>({1, 0})
    .set<Health>({100, 100})
    .add<PlayerTag>();

// 批量检查
if (e.has<Position>() && e.has<Velocity>()) { /* 可移动 */ }

// 获取实体上所有组件的 ID 列表（C API）
const ecs_type_t *type = ecs_get_type(ecs, e.id());
for (int i = 0; i < type->count; i++) {
    ecs_id_t compId = type->array[i];
    // ...
}
```

## 2.7 组件构造/析构钩子

非 POD 组件（含 vector、string 等）Flecs 自动调用构造/析构：

```cpp
struct Inventory {
    std::vector<int> items;  // Flecs 自动管理 vector 的构造/析构
    Inventory() { items.reserve(32); }
};

e.set<Inventory>({});   // 调用构造
e.destruct();           // 调用析构（vector 正确释放）
```

**注意**：含非平凡成员的组件不能被 memcpy，Flecs 会自动使用正确的拷贝/移动语义。
