# 06 · 反射与序列化

> member 注册、EcsStruct 元数据、JSON 自动序列化/反序列化。

---

## 6.1 什么是反射

Flecs 反射 = **在运行时知道组件有哪些字段**（名字、类型、偏移）。

有了反射，框架可以：

- 自动生成编辑器面板（列出所有字段 + 对应控件）
- 自动序列化/反序列化（JSON 存取）
- 动画系统按字段名写入（"Position.x" 从 0 变到 10）

---

## 6.2 注册成员（member）

```cpp
struct Transform {
    float x = 0, y = 0, z = 0;
    float rotY = 0;
};

// 手动注册每个字段
ecs.component<Transform>()
    .member<float>("x", offsetof(Transform, x))
    .member<float>("y", offsetof(Transform, y))
    .member<float>("z", offsetof(Transform, z))
    .member<float>("rotY", offsetof(Transform, rotY));
```

注册后，Flecs 知道 Transform 有 4 个 float 字段，各自在 struct 中的偏移。

### 支持的字段类型

| C++ 类型 | Flecs 类型 |
|----------|-----------|
| `float` | `flecs::F32` |
| `int32_t` | `flecs::I32` |
| `bool` | `flecs::Bool` |
| `const char*` | `flecs::String` |
| 嵌套 struct | 先注册内层 struct，再 `.member<Inner>("name", offset)` |

### 嵌套 struct 示例

```cpp
struct Vec3 {
    float x = 0, y = 0, z = 0;
};
struct Transform {
    Vec3 position;
    Vec3 rotation;
    float scale = 1.0f;
};

// 先注册 Vec3
ecs.component<Vec3>()
    .member<float>("x", offsetof(Vec3, x))
    .member<float>("y", offsetof(Vec3, y))
    .member<float>("z", offsetof(Vec3, z));

// 再注册 Transform（引用 Vec3）
ecs.component<Transform>()
    .member<Vec3>("position", offsetof(Transform, position))
    .member<Vec3>("rotation", offsetof(Transform, rotation))
    .member<float>("scale", offsetof(Transform, scale));
```

## 6.3 EcsStruct 元数据

注册 member 后，Flecs 在组件实体上挂 `EcsStruct` 组件，包含字段清单：

```cpp
// 检查组件是否有反射信息
bool hasReflection = ecs.has<Transform>(ecs.id<EcsStruct>());

// 读取字段列表（C API）
const EcsStruct *st = ecs_get_id(ecs, ecs.id<Transform>(), ecs.id(EcsStruct));
// st->members 是字段数组（name, type, offset）
```

## 6.4 JSON 序列化

注册反射后，Flecs 的 JSON addon 可以**自动**把组件转 JSON：

```cpp
// 组件 → JSON 字符串
Transform t{1, 2, 3, 45};
char *json = ecs_ptr_to_json(ecs, ecs.id<Transform>(), &t);
// 输出: {"position":{"x":[1],"y":[2],"z":[3]},"scale":[1]}
ecs_os_free(json);

// JSON → 组件
Transform t2;
ecs_ptr_from_json(ecs, ecs.id<Transform>(), &t2, jsonStr, nullptr);
```

### 实体级序列化

```cpp
// 整个实体的所有组件 → JSON
char *json = ecs_entity_to_json(ecs, e.id(), nullptr);

// JSON → 恢复实体
ecs_entity_from_json(ecs, e.id(), json, nullptr);
```

## 6.5 反射驱动的编辑器面板（原理）

```cpp
// 伪代码：自动生成 UI
void buildInspector(flecs::entity e) {
    const ecs_type_t *type = ecs_get_type(ecs, e.id());
    for (int i = 0; i < type->count; i++) {
        ecs_id_t compId = type->array[i];
        const EcsStruct *st = getStruct(compId);
        if (!st) continue;  // 无反射 → 跳过

        for (auto &member : st->members) {
            void *fieldPtr = componentData + member.offset;
            if (member.type == F32)
                addFloatSlider(member.name, (float*)fieldPtr);
            else if (member.type == Bool)
                addCheckbox(member.name, (bool*)fieldPtr);
            // ...
        }
    }
}
```

**加新组件只需注册 member → 编辑器自动显示，零 UI 代码。**

## 6.6 反射驱动的动画轨道（原理）

```cpp
// 动画轨道目标 = "组件名/字段名"（如 "Transform/position"）
void applyAnimationTrack(entity, "Transform", "position", value) {
    ecs_id_t compId = ecs_lookup(ecs, "Transform");
    const EcsStruct *st = getStruct(compId);
    int offset = findMemberOffset(st, "position");
    void *compData = ecs_get_mut_id(ecs, entity, compId);
    memcpy((char*)compData + offset, &value, sizeof(float));
}
```

## 6.7 代码生成（自动化注册）

手动写 offsetof 容易出错。可以用代码生成工具扫描头文件自动生成：

```cpp
// 工具扫描到：
struct Health {
    REFLECT float hp = 100;      // 标记需要反射的字段
    REFLECT float maxHp = 100;
    float regenTimer = 0;        // 不标记 = 运行时字段，不反射
};

// 自动生成：
ecs.component<Health>()
    .member<float>("hp", 1, offsetof(Health, hp))
    .member<float>("maxHp", 1, offsetof(Health, maxHp));
```

**注意**：`.member<T>(name, count, offset)` 三参数形式必须显式写 count=1，否则 Flecs 会用字段间隙推断数组长度（可能推错）。

---

## 6.8 哪些字段不该注册反射

| 不注册 | 原因 |
|--------|------|
| `char[256]` 路径 | 反射不支持定长 char 数组，走手工序列化 |
| `std::vector` / `std::map` | 非 POD，反射无法处理 |
| 运行时状态（timer、cache） | 不需要序列化/编辑 |
| GPU 句柄（VAO/VBO id） | 运行时重建，不存盘 |
