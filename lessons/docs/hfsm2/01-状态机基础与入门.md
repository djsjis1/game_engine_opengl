# 01 · 状态机基础与入门

> 什么是有限状态机、HFSM2 的安装与基本用法、第一个可运行状态机。

---

## 1.1 什么是有限状态机（FSM）

有限状态机 = **有限个状态** + **状态间的转换规则**。任何时刻只处于一个状态。

```
[菜单] ──按开始──→ [游戏中] ──按ESC──→ [暂停]
  ↑                   │                  │
  └────按退出─────────┘←──按继续─────────┘
```

游戏中的典型状态机：

- 全局：菜单 / 游戏 / 暂停 / 加载
- AI：巡逻 / 追击 / 攻击 / 逃跑 / 死亡
- 角色：站立 / 行走 / 跳跃 / 下落 / 着地
- 编辑器：编辑模式 / 运行模式 / 调试模式

### 为什么不用 if-else

```cpp
// ❌ 状态多了就是灾难
if (state == "menu") { ... }
else if (state == "playing") { ... }
else if (state == "paused") { ... }
// 加一个状态 → 改所有 if-else 链
```

状态机把"当前该做什么"封装在**状态对象**里，加新状态不动旧代码。

## 1.2 HFSM2 简介

[HFSM2](https://github.com/andrew-gresyk/HFSM2)：header-only C++ 层次状态机库。

- **Header-only**：只需 `#include <hfsm2/machine.hpp>`，无编译链接
- **零开销**：编译期解析，无虚函数、无堆分配、无 RTTI
- **层次化**：状态可以嵌套（父状态包含子状态）
- **类型安全**：状态转换在编译期检查
- **轻量**：核心约 3000 行模板代码

## 1.4 第一个状态机

```cpp
#include <hfsm2/machine.hpp>
#include <iostream>

// 1. 定义状态机类型（列出所有状态）
using M = hfsm2::MachineT<hfsm2::Config>;
using FSM = M::PeerRoot<
    struct Menu,
    struct Playing,
    struct Paused
>;

// 2. 定义每个状态的行为
struct Menu : FSM::State {
    void enter(Control &control) {
        std::cout << "进入菜单\n";
    }
    void exit(Control &control) {
        std::cout << "离开菜单\n";
    }
};

struct Playing : FSM::State {
    void enter(Control &control) {
        std::cout << "开始游戏\n";
    }
    void update(Control &control) {
        // 每帧调用（如果外部驱动 control.update()）
    }
    void exit(Control &control) {
        std::cout << "退出游戏\n";
    }
};

struct Paused : FSM::State {
    void enter(Control &control) {
        std::cout << "暂停\n";
    }
};

int main() {
    // 3. 创建状态机实例（初始状态 = 列表第一个 = Menu）
    FSM::Instance machine;

    // 4. 状态切换
    machine.changeTo<Playing>();   // Menu → Playing
    machine.update();              // 触发 Playing::update

    machine.changeTo<Paused>();    // Playing → Paused
    machine.changeTo<Playing>();   // Paused → Playing

    return 0;
}
```

**输出**：

```
进入菜单
离开菜单
开始游戏
退出游戏
暂停
开始游戏
```

## 1.5 核心概念

| 概念 | 说明 |
|------|------|
| `MachineT<Config>` | 状态机类型（配置模板参数） |
| `PeerRoot<S1, S2, ...>` | 扁平状态列表（所有状态平级） |
| `FSM::State` | 状态基类（继承它定义行为） |
| `Control` | 状态回调的参数（用于切换/访问上下文） |
| `Instance` | 状态机运行时实例 |
| `changeTo<S>()` | 请求切换到状态 S（下次 update 生效） |
| `immediateChangeTo<S>()` | 立即切换（不等 update） |

---

## 1.6 状态回调

每个状态可以覆写以下回调：

```cpp
struct MyState : FSM::State {
    void enter(Control &control) { }   // 进入时调用一次
    void exit(Control &control) { }    // 离开时调用一次
    void update(Control &control) { }  // 每帧调用（需外部驱动 machine.update()）
    void react(const Event &e, Control &control) { }  // 响应事件（可选）
};
```

| 回调 | 调用时机 | 典型用途 |
|------|---------|---------|
| `enter` | 状态被激活 | 初始化、播放动画、注册监听 |
| `exit` | 状态被停用 | 清理、停止动画、注销监听 |
| `update` | 每帧（外部驱动） | 持续逻辑（移动、检测条件） |
| `react` | 收到事件 | 事件驱动的转换 |

---

## 1.7 两种切换方式

```cpp
// 延迟切换：标记请求，下次 machine.update() 时生效
control.changeTo<Playing>();

// 立即切换：当场执行 enter/exit，不等 update
control.immediateChangeTo<Playing>();
```

**选择建议**：

- 游戏循环中用 `changeTo`（安全，不会在遍历中切换）
- 外部事件触发用 `immediateChangeTo`（如按钮点击、信号回调）
