## 5.1 正交区域（Orthogonal）

正交 = **多个子状态同时活跃**（并行运行）。

```cpp
// 角色同时有"移动状态"和"战斗状态"，互不干扰
struct Character : FSM::State {
    using Orthogonal = M::Orthogonal<
        struct Movement,   // 区域 1：移动（站/走/跑/跳）
        struct Combat      // 区域 2：战斗（空闲/攻击/防御）
    >;
};

// 区域 1 的子状态
struct Movement : Character::Orthogonal::State {
    using Composite = M::Composite<
        struct Idle,
        struct Walking,
        struct Running,
        struct Jumping
    >;
};

// 区域 2 的子状态
struct Combat : Character::Orthogonal::State {
    using Composite = M::Composite<
        struct Peaceful,
        struct Attacking,
        struct Defending
    >;
};
```

**效果**：角色可以"边走边攻击"（Movement=Walking 且 Combat=Attacking 同时成立）。

## 5.2 历史状态（History）

回到父状态时，**恢复到上次离开时的子状态**（而非默认第一个）。

```cpp
// 启用深度历史
using M = hfsm2::MachineT<hfsm2::Config>;

struct InGame : FSM::State {
    // Initial = 首次进入时的默认子状态
    // History = 再次进入时恢复到上次离开的子状态
    using Composite = M::Composite<
        struct Playing,
        struct Paused,
        struct Inventory
    >;
};
```

HFSM2 通过配置启用历史：

```cpp
using Config = hfsm2::Config
    ::DeepHistory;  // 深度历史：记住最内层子状态
```

**典型场景**：

- 游戏中打开背包（Playing → Inventory）
- 关闭背包 → 回到 Playing（而非默认状态）
- 暂停后继续 → 回到暂停前的状态

## 5.3 isActive 查询

检查某个状态当前是否活跃：

```cpp
// 在状态回调内
void update(Control &control) {
    if (control.isActive<Playing>()) {
        // 当前在 Playing 状态
    }
}

// 在外部代码
if (machine.isActive<Paused>()) {
    // 当前已暂停
    showPauseMenu();
}

// 检查父状态
if (machine.isActive<InGame>()) {
    // 在游戏模式中（不管是 Playing 还是 Paused）
}
```

## 5.5 状态机嵌套（Sub-machine）

一个状态内部可以包含完整的子状态机：

```cpp
struct Boss : FSM::State {
    // Boss 有自己的 AI 状态机
    using Composite = M::Composite<
        struct Phase1,    // 第一阶段（满血）
        struct Phase2,    // 第二阶段（半血，加速）
        struct Phase3,    // 第三阶段（濒死，狂暴）
        struct Dying      // 死亡动画
    >;

    void enter(Control &control) {
        // 进入 Boss 战 → 默认从 Phase1 开始
    }
};

struct Phase2 : Boss::Composite::State {
    void enter(Control &control) {
        // 加速、换技能组
    }
    void update(Control &control) {
        if (control.context().bossHp < 0.25f)
            control.changeTo<Phase3>();
    }
};
```

## 5.6 实用技巧

### 状态超时

```cpp
struct Stunned : FSM::State {
    float m_timer = 0;

    void enter(Control &control) {
        m_timer = 2.0f;  // 眩晕 2 秒
    }

    void update(Control &control) {
        m_timer -= control.context().deltaTime;
        if (m_timer <= 0)
            control.changeTo<Idle>();  // 超时恢复
    }
};
```

### 状态进入计数

```cpp
struct Playing : FSM::State {
    int m_deathCount = 0;

    void enter(Control &control) {
        // 每次进入 Playing 都计数（包括从 Paused 回来）
    }
};
```

### 外部强制切换

```cpp
// 从任何状态强制切到 GameOver（如玩家死亡）
machine.immediateChangeTo<GameOver>();
// 不管当前在哪个状态，直接跳
```

## 5.7 完整示例：AI 行为状态机

```cpp
#include <hfsm2/machine.hpp>
#include <iostream>

struct AIContext {
    float hp = 100;
    float distToPlayer = 10;
    bool playerVisible = false;
    float dt = 0.016f;
};

using M = hfsm2::MachineT<hfsm2::Config::ContextT<AIContext &>>;
using FSM = M::PeerRoot<
    struct Patrol, struct Chase, struct Attack, struct Flee
>;

struct Patrol : FSM::State {
    void enter(Control &) { std::cout << "[AI] 巡逻\n"; }
    void update(Control &c) {
        if (c.context().playerVisible && c.context().distToPlayer < 8)
            c.changeTo<Chase>();
    }
};

struct Chase : FSM::State {
    void enter(Control &) { std::cout << "[AI] 追击\n"; }
    void update(Control &c) {
        if (c.context().distToPlayer < 2) c.changeTo<Attack>();
        else if (!c.context().playerVisible) c.changeTo<Patrol>();
        if (c.context().hp < 20) c.changeTo<Flee>();
    }
};

struct Attack : FSM::State {
    void enter(Control &) { std::cout << "[AI] 攻击\n"; }
    void update(Control &c) {
        if (c.context().distToPlayer > 3) c.changeTo<Chase>();
        if (c.context().hp < 20) c.changeTo<Flee>();
    }
};

struct Flee : FSM::State {
    void enter(Control &) { std::cout << "[AI] 逃跑\n"; }
    void update(Control &c) {
        if (c.context().distToPlayer > 15) c.changeTo<Patrol>();
    }
};

int main() {
    AIContext ctx;
    FSM::Instance ai(ctx);

    // 模拟：玩家出现
    ctx.playerVisible = true;
    ctx.distToPlayer = 5;
    ai.update();  // Patrol → Chase

    // 模拟：接近玩家
    ctx.distToPlayer = 1.5f;
    ai.update();  // Chase → Attack

    // 模拟：血量低
    ctx.hp = 10;
    ai.update();  // Attack → Flee

    return 0;
}
```
